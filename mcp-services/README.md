# MCP Services

This folder contains MCP (Model Context Protocol) server implementations for various capabilities.

Each capability is documented in its individual folder, for example:

| Service | Description |
|---------|-------------|
| [web-search](web-search/README.md) | Web search capabilities |

## Service Structure

Each MCP service is expected to follows this structure:

- `README.md` — Service overview and setup instructions
- `product/` — User stories and product requirements (if applicable)
- `specifications/` — Feature specifications (if applicable)
- `src/` — Source code
- `test/` — Test files (if applicable)
